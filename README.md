# Zigtronics Website

Responsive website for Zigtronics, Inc., featuring services, project photos, and contact information.

## Files

- `index.html` — page content and layout.
- `styles/style.css` — colors, typography, and responsive styling.
- `scripts/script.js` — gallery, navigation, and photo viewer.
- `assets/` — photos, logo, and favicon.
- `.nojekyll` — disables Jekyll processing on GitHub Pages.

## Usage

Open `index.html` in a browser to preview. Upload all files and folders to your GitHub Pages publishing folder, keeping their structure intact.

Edit content in `index.html`, styling in `styles/style.css`, and behavior in `scripts/script.js`. Replace images in `assets/` or update their paths. Google Fonts requires internet access; fallback fonts work offline.
